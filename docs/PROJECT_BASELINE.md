# Project baseline

Baseline imported from the working v0.2.0-test APK.

## Functions

- Custom HOME launcher.
- App allowlist.
- Password-protected admin area.
- App list shows icon and user-facing app name only.
- Toggle changes save immediately.
- Accessibility guard returns the user to Home when a non-allowed app opens.
- Admin session can open required system settings.
- SUPRA branding and icon.
- GitHub Release update checker.

## Android

- Application ID: `vn.supra.pdalauncher`
- minSdk: 23
- targetSdk: 35
- compileSdk: 35
- Java: 17

## Update limitation

The app is not Device Owner. Android still requires confirmation in the system package installer for APK updates.
